# Домашнее задание №3: Generics

В данном проекте реализованы две задачи:
1. **Generic Repository** — In-memory хранилище для сущностей с интерфейсом `IEntity`.
2. **CollectionUtils** — Статический класс с методами `Distinct`, `GroupBy`, `Merge` и `MaxBy`, реализованными без использования LINQ.

## Как запустить

1. Убедитесь, что у вас установлен .NET SDK (рекомендуется версия 8.0 или выше).
2. Перейдите в папку проекта:
   ```bash
   cd Generics
   ```
3. Запустите проект:
   ```bash
   dotnet run
   ```

## Описание файлов
- `IEntity.cs`: Интерфейс для сущностей с обязательным полем `Id`.
- `Repository.cs`: Обобщенный репозиторий с поддержкой O(1) доступа по Id.
- `Entities.cs`: Примеры классов `Product` и `User`.
- `CollectionUtils.cs`: Утилиты для работы с коллекциями (логика на циклах и словарях).
- `Program.cs`: Демонстрация всех функций на русском языке.
