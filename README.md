# TaskHub — финальный проект

**TaskHub** — консольное приложение для управления задачами: создание, редактирование, поиск, статистика, сохранение в файл и фоновые уведомления о просроченных дедлайнах.

### Возможности

| Функция | Описание |
|--------|----------|
| Создание задачи | Название, описание, приоритет (Low / Medium / High), дедлайн, статус (New / InProgress / Done) |
| Просмотр | Все задачи, выполненные, невыполненные, с высоким приоритетом |
| Редактирование | Название, описание, приоритет, статус |
| Удаление | По выбору из списка |
| Поиск | По названию, статусу, приоритету |
| Статистика | Всего, выполнено, просрочено, разбивка по приоритетам |
| Файл | Сохранение и загрузка задач (JSON, async/await) |
| Фон | Проверка дедлайнов каждые 5 секунд и уведомления о просрочке |

### Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download) (или совместимая версия runtime)

Проверка установки:

```bash
dotnet --version
```

### Запуск

```bash
cd TaskHub
dotnet run
```

Сборка без запуска:

```bash
cd TaskHub
dotnet build
```

Данные сохраняются в `tasks.json` в папке сборки (например, `TaskHub/bin/Debug/net10.0/tasks.json`).

### Структура проекта

```
TaskHub/
├── Program.cs              # Точка входа
├── Models/                 # TaskItem, Priority, TaskItemStatus
├── Core/                   # TaskManager, статистика, generic-фильтры
├── Storage/                # TaskFileStorage (async, IDisposable)
├── Background/             # DeadlineMonitor (фоновая проверка)
└── UI/                     # Меню и консольный ввод/вывод
```
